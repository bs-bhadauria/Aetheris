# Aetheris XR Live Interactive Demo (GitHub Pages Setup)

This directory contains the **zero-backend, standalone 3D WebXR Interactive Demo** of Aetheris.

Anyone visiting your public GitHub repository can test the 3D gaze raycasting, spatial document navigation, PDF upload, and floating spatial notes directly in their browser without installing Python or setting up a server!

---

## 🚀 How to Enable GitHub Pages in 1 Minute

1. Go to your public GitHub repository (**`aetheris-showcase`**).
2. Click **Settings** (tab at the top).
3. In the left sidebar, click **Pages** (under the "Code and automation" section).
4. Under **Build and deployment**:
   * **Source**: Select `Deploy from a branch`.
   * **Branch**: Select `main` (or `master`) and directory `/ (root)` or create a copy of `index.html` at the repository root.
5. Click **Save**.

Your live interactive showcase will be live at:
`https://<your-username>.github.io/aetheris-showcase/demo/`!
